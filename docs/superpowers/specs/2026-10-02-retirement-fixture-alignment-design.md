## Design

1. Keep the intentional inherited --test-isolation=none mode. Registration and
   completion after-hook assertion failures must explicitly set a nonzero
   process exit code before rethrowing. A not-ok report paired with exit0 is
   refused, not accepted. Existing complete TAP and exact-name gates remain.
2. Canonicalize only freshly created test-owned temporary roots before embedding
   their workspace path. Do not canonicalize production/caller-controlled paths
   or expand the production /var alias contract. Negative symlink/mode/race
   fixtures must still exercise their nominated fault.
3. Real historical profiles require real secure ancestors. Construct those
   fresh roots beneath the actual OS account home, not world-writable
   /private/tmp. Authenticate that fixed parent chain with held no-follow
   descriptors, real UID/mode/directory checks and stable path/held identity;
   require account ownership at the home leaf. Newly created leaves are0700.
   Recheck parent identity after creation with exact BigInt identities. Never
   chmod a shared ancestor or fake actual historical metadata. Drain all owned
   parent descriptors in reverse, retaining primary/close causes. On uncertainty
   report the exact new leaf locator and preserve it; do not delete through a
   crossed parent. Successful caller cleanup addresses only its newly owned leaf.
4. Route the copied cutover observer's workspace-module import to the same
   physical fixture module used by retirement. Require each replacement exactly
   once and preserve actual source functions/guards.
5. The post-lock race must prove the hook ran and the original held lock existed
   before interpreting a refusal. Preserve the real descriptor census and
   withheld-close mutant. An earlier generic identity refusal is not coverage.
