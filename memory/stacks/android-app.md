# android-app Memory

## Behavior
- Gradle, Android manifest, SDK, emulator/device state, and signing are stack infrastructure.
- Native Android behavior needs emulator/device or Android test evidence.

## Recovery Recipes
- `native_tooling_infra_failure`: Treat emulator/SDK/license availability problems as environment or stack infrastructure until product code is proven faulty.

## Do Not Do
- Do not require browser DOM evidence for native Android acceptance.
